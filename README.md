Project Management Application

Developed a native Android task and project tracking application using Kotlin, focusing on software architecture, maintainable code, and efficient data management.

Implemented modern Android architecture components to ensure separation of concerns and maintainable application structure.
Applied the Repository design pattern to decouple data sources and support offline data availability and synchronization.
Designed structured navigation workflows and state management to provide a consistent user experience across multiple application screens.
Focused on modular design principles and clean code practices to improve application maintainability and scalability.

Technologies: Kotlin, Git, Software Architecture, Repository Pattern, Android Architecture Components
